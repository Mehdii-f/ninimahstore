      تغییر نام کاربری و رمز عبور

      انتشار تغییرات برای همه بازدیدکنندگان (رایگان)

      1. روی «دانلود بستهٔ انتشار» بزنید تا فایل ninimah-publish.zip دانلود شود.
      2. فایل را از حالت فشرده خارج کنید؛ دو پوشهٔ data و assets ساخته می‌شود. فایل data/admin.json داخل آن همان چیزی است که ورود از دستگاه‌های دیگر را ممکن می‌کند.
      3. در گیت‌هاب: Add file ← Upload files؛ این دو پوشه را بکشید و Commit کنید.
      4. بعد از چند دقیقه (به‌روزرسانی GitHub Pages) همه تغییرات را می‌بینند.
      5. پس از انتشار، «حذف پیش‌نویس» را بزنید تا این مرورگر هم نسخهٔ منتشرشده را نشان دهد.
